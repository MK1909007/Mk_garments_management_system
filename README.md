# Mk_garments_management_system

A web-based garments management system developed for a garments company.

## Features

- Men, Women, and Children products
- Product management
- Add, edit, view, and delete products
- Product image upload
- Customer query form
- Admin login
- MySQL database
- Responsive web interface
- JavaScript/jQuery interactions

## Technologies

- HTML5
- CSS3
- Bootstrap
- JavaScript
- jQuery
- PHP
- MySQL
